Guild System Polls

Each poll focuses on a different aspect of guilds, from shops and currency to quests and progression. Keep in mind:

  • All polls are guild-related, saying “no guild quests” doesn’t mean no quests at all.
  • Some results may affect others. For example, no merchants means no need for currency.

Extra information noted in the poll:

  • Independent progression per guild (no cross-guild interaction)
  • Global progression — total XP from all guilds unlocks things
  • Hybrid progression:
    • Per-guild unlocks (e.g. rift upgrades)
    • Global unlocks (e.g. mod access, HP increases)
  • Hybrid:
    • Main storyline via Questing Guild
    • Side quests per guild

Polls​

Guild Shops Poll How should shops work in guilds?​

  • No shops at all. Guild only exist for quest/progression
  • A single Market Guild, only place with merchants
  • Each guild has its own merchants

Currency System Poll: How should currency work between guilds? (If we have merchants)​

  • No currency system, have another form of trading.
  • A single currency, usable in all shops
  • A different currency per guild
  • Shared currency within guild groups (differ per group)

Currency Form Poll: In what form should currency exist? (If we have merchants)​

  • Digital: shown in player stats
  • Item-based: coins as physical items stored in a wallet

Guild Progression Poll: How should experience and progression work?​

  • No progression or unlocks
  • Independent progression per guild
  • Global progression
  • Hybrid progression

Quest System Poll: How should quests be distributed among guilds?​

  • No quests (related to guilds)
  • A Questing Guild handles all quests
  • Every guild has its own questline
  • Hybrid

Results​

The poll was ran from the 24/07/2025 until 31/07/2025 with the following results:

  • Guild Shops Poll How should shops work in guilds?

    • No shops at all. Guild only exist for quest/progression - 0%
    • A single Market Guild, only place with merchants - 53%
    • Each guild has its own merchants - 47%

  • Currency System Poll: How should currency work between guilds? (If we have merchants)

    • No currency system, have another form of trading. - 6%
    • A single currency, usable in all shops - 61%
    • A different currency per guild - 3%
    • Shared currency within guild groups (differ per group) - 29%

  • Currency Form Poll: In what form should currency exist? (If we have merchants)

    • Digital: shown in player stats - 60%
    • Item-based: coins as physical items stored in a wallet - 40%

  • Guild Progression Poll: How should experience and progression work?

    • No progression or unlocks - 0%
    • Independent progression per guild - 28%
    • Global progression - 0%
    • Hybrid progression - 72%

  • Quest System Poll: How should quests be distributed among guilds?

    • No quests (related to guilds) - 3%
    • A Questing Guild handles all quests - 3%
    • Every guild has its own questline - 37%
    • Hybrid - 57%
