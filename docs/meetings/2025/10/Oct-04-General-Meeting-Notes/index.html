Design Completed​

Three Pillars

  • Shape Your Own Path

Design open-ended systems where choices matter Avoid fixed roles and narrow solutions Support multiple valid playstyles

  • Meaningful Progression

Growth is earned, impactful, and exciting Unlocks what players can do and how they engage Progression changes gameplay capabilities

  • Prioritize Experience

Deliver meaningful play moments Respect player's time and capacity to learn Quality over quantity in player interactions

Design Tasks​

  • Single statement capturing what it feels like to play
  • Identify core actions (verbs) and emotions they should evoke
  • Build reference library of games evoking desired feelings

Development Focus​

Release Strategy​

  • Targeting new release (020) then expanding to newer features
  • Progress over perfection guiding principle
  • Faster turnaround of changes for team feedback
  • More frequent updates than 3-3.5 month gap since 014 update

Release 0.2.0 Priorities​

  • Wrap up ability changes
  • Include Rift Mob variants and ensure spawning
  • Release first version of anomalies for team feedback
  • Expand what quests, guilds, and anomalies can do
  • Data pack expansions

Development Philosophy​

  • Focus on working code and proof of concept ideas
  • Features will evolve with team input
  • No specific release timeframe, based on content and need
  • Not aiming for monthly release cadence
